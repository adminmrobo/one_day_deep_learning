# 하루 만에 끝내는 딥러닝 서머리 노트 — 박사의 쪽지시험 대비

AI 연구실 해설 · 딥러닝 서머리 노트 · 비전공자용

**바로 보기:** https://adminmrobo.github.io/one_day_deep_learning/

인턴 시아와 모아가 딥러닝 필기 노트 열한 장을 받았습니다. 박사의 쪽지시험은 내일입니다. 조수(하루), 초파리 연구원, 주판봇이 한 교시씩 맡아 시험에 나오는 것만 짚어 줍니다. 6교시를 마치면 종례 모의고사 열 문제를 풉니다. 코드와 수식을 몰라도 버튼만 눌러 따라갈 수 있습니다.

## 시간표

| 교시 | 내용 | 원 노트 | 도우미 |
|---|---|---|---|
| 1교시 | 딥러닝이란, 뉴런 한 개의 계산 | 1·2장 | 조수 |
| 2교시 | 활성화 함수 다섯 가지와 쓰는 자리 | 3장 | 초파리 연구원 |
| 3교시 | 순전파, 손실(벌점), 역전파, 경사 하강 | 4·5장 | 조수 |
| 쉬는 시간 | 대결 — 걸음 폭(학습률)을 키우면 빨리 끝날까 | — | 박사(심판) |
| 4교시 | 에폭·배치·이터레이션, 과적합, 조기 종료 | 5·6·10장 | 주판봇 |
| 5교시 | CNN — 합성곱, 풀링, 대표 구조, 전이 학습 | 7·8·10장 | 초파리 연구원 |
| 6교시 | RNN, LSTM, GRU, 트랜스포머 | 9·10장 | 주판봇 |
| 종례 | 모의고사 열 문제 (면접 질문 여섯 + 함정 넷) | 11장 | 박사 |

교시마다 「시험에 나오는 3줄」, 「왜 이 방법을 쓰나」, 조수의 수식 질문, 직접 해 보기, 박사의 쪽지시험 두 문제가 있습니다. 쪽지시험은 모두 23문항입니다.

## 노트 검산 — 원 노트와 다르게 쓴 일곱 곳

| 노트의 자리 | 원 노트 | 이 페이지 |
|---|---|---|
| 3장 비교표 | 소프트맥스는 출력층에서만 쓴다 | 주로 출력층에 쓴다 |
| 5.2 벌점 그림 | 확률 0.5에서 가장 낮은 U자 곡선 | 정답이 1이면 내려가기만, 0이면 올라가기만 하는 곡선 |
| 7.2 합성곱 예제 | 0·1·0 / 1·2·1 / 0·1·0 | −1·1·2 / −2·0·3 / 0·−2·1 (아홉 칸 중 일곱 칸이 다름) |
| 7.3 돋보기 이름 | Sharpen, Blur | 둘 다 윤곽선 찾기 계열 |
| 8.6 LeNet 출력 | 100 classes | 10가지 (숫자 0~9) |
| 11장 빠른 요약표 | GRU: 3 gates | GRU는 문 2개 |
| 11.2와 11.9의 표기 | 괄호가 열린 채 끝남 · 번호가 1 다음 3 | ŷ = f(z) · 번호 1, 2 |

## 읽을 때 알아 둘 점

- 직접 해 보기의 숫자는 페이지 안에서 계산한 **설명용 모형**의 값입니다. 실제 학습 기록이 아닙니다.
- 대결의 승패는 "벌점이 L = (w − 3)²인 골짜기에서 걸음 폭 0.1과 1.05를 견준" 결과입니다. 걸음 폭 0.5이면 한 걸음에 끝난다는 점도 대결 아래에 적었습니다.
- 원 노트(IT Hub Official 표시)의 게시 주소와 저자는 확인하지 못했습니다. 참고문헌의 쪽수·절 번호도 원문과 대조하지 않았습니다. 페이지의 「확인 필요 목록」에 모았습니다.
- 표지와 교시 머리의 게임 화면은 코드로 그린 것입니다. 같은 콘셉트의 그림 지시문은 `docs/COVER_one_day_deep_learning.md`에 있습니다. 로봇은 주판봇만 씁니다.
- CNN을 더 자세히 보려면 [얼굴 알아맞히기 게임 — 20칸으로 배우는 CNN](https://adminmrobo.github.io/cnn_face_game_lab/)으로 이어집니다.
